## 2. THE CHALLENGE

### Headline
Static graphics get ignored. Unoptimized animations slow down your web pages.

### Body
Modern audiences respond to motion, but poor implementation hurts your product. Heavy video files or unoptimized animation scripts drag down website PageSpeed metrics, leading to high bounce rates. Furthermore, if animations do not align with your product's user interface, they feel like unnecessary clutter. To utilize motion successfully, you need lightweight, vector-based files (like Lottie/JSON) that render dynamically at 60 FPS without slowing down page load times. Quecko builds motion graphics with engineering in mind. We design sleek animations, export them as lightweight vector scripts, and integrate them into interfaces to keep layouts performant.

## 12. FAQs

**What is a Lottie animation and why use it?**
A Lottie is an open-source animation file format that compiles After Effects vectors into JSON data. It allows developers to render high-quality animations dynamically on web and mobile with tiny file sizes.

**Will custom animations slow down our website?**
If using heavy video formats (MP4/GIF), yes. By designing with vector-based Lottie JSON scripts, we keep file sizes small, ensuring animations load in milliseconds without hurting PageSpeed.

**Can we edit the colors of a Lottie animation after it's built?**
Yes. Because Lottie files are code-based JSON scripts, developers can target color parameters dynamically via CSS/JS parameters, allowing for interactive state changes.

**What is the timeline for a 60-second explainer animation?**
Timelines typically range from 4 to 6 weeks based on storyboard iterations, custom asset designs, and animation complexities.
